#  Inteligencia Artificial y Ciencia de Datos

Portafolio de proyectos y actividades desarrollados como parte de mi formación en la **Licenciatura en Ciencias Computacionales de la Universidad Autónoma de Nuevo León (UANL)**.

Este repositorio reúne diferentes ejercicios enfocados en **Python, análisis de datos, fundamentos matemáticos e Inteligencia Artificial**, realizados con el objetivo de desarrollar habilidades prácticas y complementar los conocimientos adquiridos durante mi formación académica.

##  Objetivo

El objetivo de este portafolio es documentar mi proceso de aprendizaje y mostrar la aplicación práctica de diferentes conocimientos relacionados con programación, análisis de datos e Inteligencia Artificial.

A lo largo de las actividades trabajé con diferentes herramientas y conceptos, desde fundamentos de programación con Python hasta el manejo y análisis de información utilizando librerías especializadas.

##  Tecnologías y herramientas

Durante las diferentes actividades utilicé principalmente:

- Python
- Pandas
- Jupyter Notebook
- Git
- GitHub
- Kaggle

Además, se trabajaron conceptos matemáticos y estadísticos necesarios para el análisis de datos y el aprendizaje automático.

##  Conocimientos desarrollados

Las actividades realizadas me permitieron reforzar conocimientos relacionados con:

- Programación en Python.
- Manipulación y análisis de datos.
- Uso de Pandas.
- Operaciones con matrices.
- Probabilidad y estadística.
- Preparación de datos.
- Fundamentos de Inteligencia Artificial.
- Resolución de problemas mediante programación.
- Uso de herramientas para ciencia de datos.

##  Contenido del repositorio

El repositorio documenta diferentes etapas de aprendizaje realizadas a lo largo del curso.

###  Enero – Febrero

Durante esta etapa se trabajó principalmente con fundamentos necesarios para comenzar a desarrollar proyectos relacionados con programación y análisis de datos.

Entre las actividades se encuentran:

- Introducción a la programación.
- Programación utilizando Python.
- Ejercicios prácticos.
- Trabajo con matrices.
- Ejercicios de probabilidad.
- Introducción al manejo de datos.

###  Marzo

En esta etapa se continuó desarrollando los conocimientos adquiridos mediante nuevas actividades y ejercicios enfocados en la aplicación práctica de las herramientas estudiadas.

###  Abril – Mayo

La última etapa reúne actividades y evidencias relacionadas con los conocimientos desarrollados durante el curso, además de certificaciones obtenidas como parte de la formación complementaria.

##  Aprendizaje obtenido

Este portafolio representa una parte de mi proceso de formación en **Inteligencia Artificial y Ciencia de Datos**.

Las diferentes actividades me permitieron fortalecer mis conocimientos de Python y comprender mejor cómo herramientas como Pandas pueden utilizarse para manipular y analizar información.

También pude reforzar conceptos matemáticos y estadísticos importantes para áreas como la ciencia de datos y el aprendizaje automático.

Más allá de las actividades individuales, este repositorio muestra la evolución de mis conocimientos y mi experiencia utilizando diferentes herramientas para resolver problemas mediante programación y análisis de información.
